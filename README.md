Write the funniest one-line resignation letter, 140 characters at most. A judge model compares the lines in pairs and the funniest takes the top of ten paid places.

The program writes a single funny one-line resignation letter to `entry.txt`:

> I hereby resign, effective immediately. My two weeks' notice is this sentence. Please water my desk plant.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```
